# Politique de sécurit

## Signaler un problème de sécurité

Si vous découvrez un problème de sécurité concernant ce dépôt, merci d’utiliser la fonctionnalité privée « Report a vulnerability » de GitHub.

Ne publiez aucune donnée sensible dans une issue publique.

## Utilisation responsable

Ce dépôt est proposé exclusivement à des fins pédagogiques.

Les commandes et démonstrations doivent être utilisées uniquement sur vos propres systèmes, dans un laboratoire isolé, dans une machine virtuelle ou avec l’autorisation explicite du propriétaire du système concerné.
